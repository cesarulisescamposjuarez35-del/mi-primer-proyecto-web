
# Tecnología y Videojuegos

## Descripción

Este proyecto consiste en una página web sencilla sobre tecnología y videojuegos.

La página presenta información básica sobre la tecnología, los videojuegos y algunos videojuegos populares.

## Tecnologías utilizadas

- HTML5
- CSS3
- Visual Studio Code
- Git
- GitHub

## Contenido

La página contiene las siguientes secciones:

- Tecnología
- Videojuegos
- Videojuegos populares
- Importancia de la tecnología y los videojuegos
- Contacto

## Objetivo

El objetivo de este proyecto es crear una página web utilizando HTML y CSS y posteriormente publicarla en GitHub mediante Git.
